# 出荷CSV → 納品明細Excel/PDF 自動生成ツール 設計書

- 日付: 2026-11-23
- 状態: 承認済み

## 目的（なぜ作るか）

初めての有料開発案件を受注するための営業用ポートフォリオ。実際の顧客に提示できる、
小規模で信頼性の高いデモを作る。売りは「派手さ」ではなく次の3点。

1. 間違ったデータを黙って帳票にしない（要確認一覧へ回す）
2. 元データを壊さない
3. 初心者でもダブルクリックで動かせる

## ゴール / 非ゴール / アンチゴール

- ゴール: 出荷CSV（1形式）を読み、伝票番号ごとに納品明細Excel（テンプレート流し込み）と
  PDFを出力する。必須欠損・数量不正・重複IDを検出し、要確認一覧へ出力する。
- 非ゴール: 複数CSV形式への対応、複数帳票形式、消費税計算、GUIアプリ化、DB連携。
- アンチゴール: 問題行を自動修正する／一部の明細が欠けた伝票を出力する／元CSVを変更する／
  データを外部（AI含む）へ送信する。

## 制約

- Python（3.10以上）、Mac で開発・実行
- 検証データは架空10行（正常8行・異常2行）
- テストコードとREADMEを用意し、GitHubで公開できる状態にする

## 方式の比較

| 方式 | 内容 | 判断 |
|---|---|---|
| A. openpyxl + reportlab | Excelはテンプレート流し込み、PDFはreportlabで同レイアウトを描画 | **採用**。追加インストール不要で初心者環境でも動く |
| B. Excel → PDF 変換 | LibreOffice / Excel を外部コマンドで呼び出して変換 | 不採用。LibreOfficeの導入が必要で、初心者向けでない |
| C. pandas で読み込み | DataFrameで集計 | 不採用。先頭ゼロの商品コードが壊れやすく、依存が重い |

## ライブラリ

`openpyxl`（Excel）、`reportlab`（PDF、内蔵CIDフォント HeiseiKakuGo-W5）、`pytest`（テスト）。
CSVは標準 `csv` モジュール。

## 入力CSV

列: `伝票番号, 明細ID, 出荷日, 得意先コード, 得意先名, 商品コード, 商品名, 数量, 単位, 単価, 備考`

- 文字コード: UTF-8（BOM有無とも）→ 失敗時 Shift_JIS(cp932) を自動判別
- 必須: 伝票番号, 明細ID, 出荷日, 得意先名, 商品コード, 商品名, 数量, 単価
- 数量: 1以上の整数
- 単価: 0以上の数値（Decimal）
- 出荷日: YYYY-MM-DD または YYYY/MM/DD
- 明細ID: ファイル全体で一意
- 列不足（ヘッダ不一致）の場合は処理全体を止めてエラー表示

## チェック規則（承認済みの判断）

1. 必須欠損 / 数量不正 / 単価不正 / 日付不正 / 重複ID を行単位で検出
2. 重複IDは、該当する全行を要確認にする（どちらが正しいか判断しない）
3. 同一伝票内で出荷日・得意先コード・得意先名が食い違えば「ヘッダ不一致」
4. 明細数がテンプレート上限（15行）を超える伝票は「明細行数超過」
5. **1行でも問題がある伝票は伝票ごと出力を保留**し、その伝票の全行を要確認一覧へ
   （問題のない行は「同一伝票内に要確認行あり」として掲載）
6. 自動修正は一切しない

## 出力

`output/YYYYMMDD_HHMMSS/` に毎回新規作成（上書きしない）。

- `excel/納品明細_<伝票番号>.xlsx` … テンプレートに流し込み
- `pdf/納品明細_<伝票番号>.pdf` … 伝票単位
- `要確認一覧.xlsx` … 行番号, 明細ID, 伝票番号, 区分, 内容, 元データ（加工なし）
- `処理結果.txt` … 件数サマリ

帳票項目: 見出し（伝票番号・出荷日・得意先コード・得意先名・発行日）、明細（No, 商品コード,
商品名, 数量, 単位, 単価, 金額, 備考）、合計数量・合計金額（税抜）。

## 実装上の注意

- 元CSVは読み取り専用で開く。テストで前後のハッシュ一致を確認
- 値が `= + - @` で始まっても数式化しない（文字列として書き込む）
- 金額は Decimal、商品コード等はすべて文字列のまま扱う
- 伝票番号はファイル名に安全な文字へ置換
- 外部通信なし。実データは `.gitignore` 対象（`output/`, `input/`）

## 操作方法

- `セットアップ.command`: 初回のみダブルクリック（venv作成・ライブラリ導入）
- `実行.command`: ダブルクリックでCSVを選択（未選択ならサンプル）→ 出力フォルダを開く
- コマンド派向け: `python -m shipdoc <csv>`

## 実装者に委ねる事項

テンプレートの見た目（罫線・色）、PDFのレイアウト細部、エラーメッセージの文言。
